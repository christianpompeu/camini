# Camini • FORÇA — protótipo visual gerado

38 telas PNG em orientação mobile, nomeadas por número e fluxo. As telas 01–34 recriam estados presentes no protótipo do Figma. As telas 35–38 são propostas para completar a arquitetura do catálogo de exercícios.

## Telas propostas além do Figma

- 35 — Catálogo administrativo de exercícios
- 36 — Cadastro estruturado de exercício
- 37 — Gestão de mídias do exercício
- 38 — Revisão de lacunas do catálogo para a IA

## Uso

Estas imagens são referências visuais para discussão e prototipação. Não são telas implementadas, nem fonte de verdade para conteúdo de treino. Revise nomes, exercícios, medidas e textos antes de usá-las como especificação no Antigravity. Imagens de exercícios geradas para demonstrar um espaço visual não substituem as mídias oficiais do Drive. Dados de histórico, cargas e sugestões devem ser tratados como ilustrativos.

Identidade: mobile-first, neutra, monocromática, alinhada ao padrão atual do Camini e a componentes shadcn.
